# 🎮 Annakut Family Path — Swaminarayan Hariprabodham Parivar

An 8-bit retro side-scroller game celebrating family harmony, right choices, and devotion for the Annakut festival booth exhibition.

---

## 🕹️ Controls (3-Key Dedicated Setup)

The game is designed from the ground up for a **3-key hardware button box / keyboard**:

| Button | Primary Key | Keypad / Macro Keys | Action |
|:---:|:---:|:---:|:---|
| **Left** | `A` | `1` or `Num1` or `Left Arrow` | Select Left choice dilemma |
| **Center** | `S` | `2` or `Num2` or `Down Arrow` / `Space` | **Hold to Walk Forward** / Start / Restart |
| **Right** | `D` | `3` or `Num3` or `Right Arrow` | Select Right choice dilemma |

### Booth Shortcuts:
* **`F`**: Toggle Fullscreen mode
* **`M`**: Mute / Unmute 8-bit sound effects & chiptune melody
* **Touch / Click Support**: Tapping on the left 1/3, center 1/3, or right 1/3 of the screen also acts as the 3 buttons for tablet booths!

---

## 🌟 Key Features

1. **Zero Dependencies & Offline Ready:**
   * Pure HTML5 Canvas and Vanilla JavaScript.
   * Synthesized 8-bit chiptune sound effects & peaceful devotional background melody via the Web Audio API — **no external audio or image files required to run**.
   * Double-click `index.html` to run anywhere without internet, server, or software installation.

2. **Bilingual Content (English & Gujarati):**
   * Prompts, zone announcements, and choice dilemmas are written in both English and Gujarati (e.g., `બાગ પ્રવેશ`, `પરિવાર સાથે જમવું`, `દાદા-દાદી સાથે વાતો`).

3. **Moral & Family Reflections:**
   * Every choice gives instant reflective feedback reinforcing family unity, respect for elders, daily devotion, and forgiveness.

4. **Dynamic Anti-Cheat Shuffling:**
   * The good and bad choices randomly shuffle between Left (`A`) and Right (`D`) on each run so players must read and reflect rather than memorize button sequences.

5. **Smooth Rollback System:**
   * Making a poor choice causes the character to stumble with a retro rewind sound, safely rolling back to the previous checkpoint.

6. **Kiosk & Exhibition Friendly:**
   * **Inactivity Auto-Reset:** If a player walks away mid-game, the game automatically resets to the Title / Attract screen after 40 seconds of inactivity.
   * **Pilgrim Tracker:** Automatically tracks how many total visitors reached the Mandir today in `localStorage`.
